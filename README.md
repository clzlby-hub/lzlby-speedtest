# LibreSpeed TV (lzlby-speedtest)

专为 Android TV / Google TV / 索尼 BRAVIA 电视定制的 **Apple TV 质感全功能网络测速应用**。

---

## ✨ 核心特性

- **📺 Apple TV 原生级视觉与交互**：
  - 玻璃拟态（Glassmorphism）暗黑主题，精致发光波形图与高帧率拟物测速表盘。
  - 针对电视遥控器（D-pad）深度优化，按键高亮缩放，永不丢焦，按返回键秒级响应。
- **🌐 双测速模式一键无缝切换**：
  - **测公网直连（物理宽带）**：使用直接连接，实时显示本地宽带公网 IP（中国移动/电信/联通），测出真实入户宽带极限带宽。
  - **测代理专线（出海专线）**：直连本地代理核心（`127.0.0.1:7890`，支持 FlClash、Clash Meta、Mihomo），即使在 VPN“访问控制”外也能直接测出当前出海专线真实速度及代理出口 IP。
- **🇨🇳 国内三大运营商骨干网与运营商智能匹配**：
  - 内置腾讯云移动骨干网、华为云电信专网、阿里云联通骨干网、CERNET 教育网骨干等精选测速节点。
  - 智能运营商匹配：根据公网 IP 自动匹配专属运营商服务器，并以全网并发探针实时选择最低延迟节点。
- **🏠 自建局域网 / 内网 Docker 测速**：
  - 专属 TV 弹窗，一键预设填入常用局域网 IP（`192.168.1.1`、`192.168.0.1`、`10.10.2.1` 等），轻松测试软路由、NAS 与千兆/万兆内网局域网极限速率。
- **⚡ 现代高并发测速引擎**：
  - 多线程高吞吐，实时计算瞬时速率与平滑带宽；连接生命周期严格受控，随时点击“停止测速”立即中断，彻底杜绝 ANR 和卡死。

## 🛠️ 编译与打包

```bash
# 编译 Debug APK
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
./gradlew assembleDebug
```
编译产物位于 `app/build/outputs/apk/debug/app-debug.apk`。
